## crownfield-eye-hospital-database

Relational database development project for Crownfiel Eye Hospital using MySQL.

# Crownfield Eye Hospital – Database Project
 
# Project Overview
 
This project focuses on designing and developing a relational database prototype for Crownfield Eye Hospital NHS Foundation Trust.
 
The aim is to improve the management of hospital information by replacing the use of separate paper records, Word documents and Excel spreadsheets with a structured database.
 
The proposed database will help organise and manage information about patients, clinicians, specialties, clinics, appointments, diagnoses, prescriptions, medicines, treatments and follow-up plans.
 
# Project Objectives
 
Identify problems with the existing data management system.
 
Analyse the data and apply database normalisation up to Third Normal Form (3NF).
 
Design an Entity Relationship Diagram (ERD) using MySQL Workbench.
 
Create the relational database structure with appropriate primary and foreign keys.
 
Implement relationships and constraints to improve data integrity.
 
Insert sample data and test the database using SQL queries.
